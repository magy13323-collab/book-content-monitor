# Происхождение демонстрационных материалов

Демонстрация использует вымышленные книги, авторов и локальные файлы. Синтетические входы воспроизводятся [генератором](../examples/create_synthetic_assets.py); он создаёт только входные материалы, а не результаты классификации. Существующие входы не перезаписываются без явного `--replace`.

| Материал | Происхождение и назначение |
|---|---|
| [synthetic_input.xlsx](../examples/synthetic_input.xlsx) | Создан генератором. `Records` содержит 18 строк для нормализации, группировки и Review; `Catalog` — семь проверок одной ожидаемой книги |
| `examples/fixtures/own.html` и `foreign.html` | Искусственные карточки собственной и другой книги с локальными признаками файлов |
| `examples/fixtures/uncertain.html` и `dynamic.html` | Искусственные загрузочные оболочки; динамическая карточка появляется после выполнения JavaScript |
| `examples/fixtures/own.pdf` и `foreign.pdf` | Искусственные двухстраничные PDF с вымышленными метаданными и коротким текстом, написанным для демонстрации |
| `examples/fixtures/review.pdf` | Искусственный PDF с явной ролью Book review; его текст не выдаётся за текст произведения |
| `tests/fixtures/` и данные внутри тестов | Синтетические HTML/PDF и строковые сценарии для проверки сопоставления, извлечения и транспорта; они не являются выгрузками реальных книг или сайтов |

Avery Demo / DemoBook Aurora 101 и Robin Sample / DemoBook Boreal 202 обозначают роли собственной и чужой книги. Русскоязычные имена и названия на листе `Records` также вымышлены и служат примерами неоднозначных записей.

## Адреса и офлайн-режим

`library.example` используется как идентификатор локальных фикстур. [run_demo.py](../examples/run_demo.py) подставляет их вместо HTTP-ответов и запрещает непредусмотренные запросы. Chromium получает известные маршруты из локальных HTML; неизвестные адреса блокируются. Сетевой запуск `part2.py` напрямую на демонстрационных URL не является офлайн-демонстрацией.

Иные URL в тестах — искусственные входы транспортных сценариев. Тесты используют подменённые ответы и браузерные маршруты; общая фикстура запрещает неперехваченные HTTP-запросы.

## Настоящие результаты

В [examples/output](../examples/output/) сохранены три согласованных файла одного запуска `--browser off` от 29 октября 2026 года:

- [part1_processed.xlsx](../examples/output/part1_processed.xlsx) — результат обработки первого листа;
- [part2_results.xlsx](../examples/output/part2_results.xlsx) — табличные результаты семи проверок;
- [part2_results.jsonl](../examples/output/part2_results.jsonl) — те же проверки со структурированными доказательствами.

Файлы созданы неизменёнными CLI проекта через demo-wrapper. Значения `status`, `reason_code` и `evidence` не задавались вручную. Все 44 поля семи результатов JSONL/XLSX сверены, исходный Excel сохранился без изменений. PDF-рецензия фактически получила `2 / pdf_document_role_unresolved`, динамическая страница — `2` в `off` и `1` после JavaScript в `auto`.

Локальный полный прогон публичного корпуса: 1592 passed, 0 failed, 0 errors, 0 skipped. Это результат функциональной проверки существующего окружения, а не подтверждение чистой установки или удалённого CI.

## Скриншоты

[Снимки](screenshots/README.md) получены нативным захватом настоящих окон Windows. Терминал показывает новый успешный demo-запуск на тех же входах с выводом во временный каталог. Таблицы показывают побайтовые временные копии приложенных XLSX в установленном LibreOffice Calc.

Для читаемости изменены только настройки отображения: ширина и видимость колонок, шрифт, высота строк и масштаб. Значения не редактировались; изменения вида не сохранялись в приложенные XLSX. Синтетические результаты на снимках сверены с исходными экспортами. Изображения не сгенерированы и не собраны из нарисованных элементов интерфейса.

В публичных примерах нет реальных пользовательских реестров, текстов сторонних книг, секретов и личных абсолютных путей. Зависимости перечислены в requirements и не включены в репозиторий своими копиями.
