# Настоящие скриншоты

Снимки сделаны 29 октября 2026 года нативным захватом окон Windows (`PrintWindow`). Изображения не генерировались и не перерисовывались. Личные пути, другие окна рабочего стола и пользовательские данные в кадр не включены. Снимки показывают экспорты от 29 октября; текущие файлы обновлены настоящим запуском 31 октября 2026 года. Показанные значения и статусы сохранились; исправленный заголовок `Правообладатель` находится в скрытой колонке `A` листа `Normalized`.

| Файл | Что показано | Источник данных |
|---|---|---|
| [01-demo-cli.png](01-demo-cli.png) | Настоящий PowerShell в conhost: успешный запуск `off`, exit code 0 и сводка, прочитанная из созданного этим запуском JSONL | Неизменённая временная копия [demo](../../examples/run_demo.py) и текущих синтетических входов |
| [02-normalized.png](02-normalized.png) | Лист Normalized: исходные поля слева, номер исходной строки и нормализованные поля справа | Экспорт от 29 октября в LibreOffice Calc; [актуальный part1_processed.xlsx](../../examples/output/part1_processed.xlsx) содержит исправленный заголовок вне кадра |
| [03-results.png](03-results.png) | Семь настоящих результатов `off`: статусы, reason_code, полные причины и evidence | Экспорт от 29 октября в LibreOffice Calc; показанные поля совпадают с [актуальным part2_results.xlsx](../../examples/output/part2_results.xlsx) |

Microsoft Excel для съёмки не использовался: показан установленный LibreOffice Calc, открывающий настоящие XLSX. Для читаемости изменены ширина и видимость колонок, высота строк, шрифт и масштаб. Значения не редактировались. Настройки вида оставались в памяти редактора; при съёмке исходные Excel-файлы не перезаписывались.

В `Results` все семь значений `status`, `reason_code`, `reason` и массивов `evidence` сверены с [сохранённым JSONL](../../examples/output/part2_results.jsonl). Терминальный запуск создал отдельные временные файлы; его статусы и доказательства совпадают с приложенным запуском `off`.

Подробнее о вымышленных книгах, генераторе HTML/PDF и офлайн-маршрутах — в [описании происхождения материалов](../data-provenance.md).
